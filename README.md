# Simulation Studio

Simulation Studio is a reusable engine and development framework for premium interactive educational simulations in mathematics, physics, chemistry, and biology.

This repository is not the full Al Mou3allem platform. It does not include authentication, subscriptions, LMS workflows, student accounts, parent dashboards, messaging, or backend business systems.

## Current Phase

Phase 0: repository foundation.

The immediate goal is to establish a strict React, TypeScript, and Vite application with concise repository documentation, QA commands, dependency tracking, and reviewer playbooks. The first simulation prototype will be Electromagnetic Induction, but large simulation implementation must wait until the specification and shared core are ready.

## Commands
