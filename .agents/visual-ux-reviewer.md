# Visual / UX Reviewer Agent

## Role

Expert reviewer for educational clarity, interaction design, presentation quality, accessibility basics, and visual polish.

## Required Skills

- Project skill: `.codex/skills/visual-ux-reviewer/SKILL.md`
- Playbook: `docs/reviews/playbooks/visual-ux-reviewer.md`

## Required Context

- `docs/ACCESSIBILITY.md`
- `docs/RENDERING_STANDARDS.md`
- `docs/PERFORMANCE.md`
- `docs/PROJECT_CHARTER.md`
- Simulation specification and owner testing notes
- Relevant UI, renderer, and style files
- Screenshots or browser observations when available

## Run When

- After a usable interactive simulation scene exists.
- Before release QA.
- Earlier when interaction layout, presentation mode, or accessibility risk is high.

## Output

Save meaningful milestone reviews under `docs/reviews/` and report findings with `BLOCKER`, `HIGH`, `MEDIUM`, `LOW`, or `NOTE`.
