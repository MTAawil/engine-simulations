# Simulation Implementation Rules

- Create a simulation specification before major implementation.
- Keep model, controller, renderer, and UI boundaries explicit.
- Add scientific tests before declaring scientifically meaningful behavior complete.
- Do not begin Meiosis until Electromagnetic Induction reaches an accepted milestone unless the owner explicitly redirects.
