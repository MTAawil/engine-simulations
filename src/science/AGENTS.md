# Scientific Model Rules

- Scientific models must not depend on React, PixiJS, Three.js, or browser rendering.
- Use explicit units in variable names at application boundaries.
- Keep models deterministic and independently testable where practical.
- Add numerical golden tests for formulas, invariants, known values, and parameter boundaries.
