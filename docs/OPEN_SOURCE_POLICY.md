# Open Source Policy

Simulation Studio must remain proprietary-capable.

Do not assume a GitHub repository is commercially safe. Code, assets, textures, models, datasets, fonts, and screenshots can have different licenses.

Do not copy PhET source code, assets, screenshots, layouts, branding, or visual identity. General scientific laws and educational ideas may be independently implemented.

If a fork or patch to a third-party dependency becomes unavoidable, stop and create an ADR before implementation.
