# Architecture Decision Records

Create lightweight ADRs only for consequential decisions.

Use this template:

```md
# ADR N: Title

## Status

Proposed | Accepted | Superseded

## Context

## Decision

## Alternatives

## Consequences
```

ADR-worthy examples include changing the core simulation API, adopting a major state system, forking a dependency, replacing PixiJS/Three.js, adding a backend, changing licensing strategy, or moving to a monorepo.
