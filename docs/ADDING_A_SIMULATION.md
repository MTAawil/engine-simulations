# Adding A Simulation

Before coding a major simulation, create a specification that includes:

- educational objective
- target concepts
- scientific assumptions
- formulas/models
- variables and units
- parameter ranges
- controls
- visual states
- animation states
- graphs
- labels
- presets
- edge cases
- test cases
- accessibility notes
- performance concerns
- acceptance criteria

Store specifications under the relevant simulation directory.

Implementation must keep model, controller, renderer, and UI concerns separate.
