# Project Charter

Simulation Studio is a reusable, maintainable framework for premium scientific and educational simulations. It is intended to be embedded into a larger education platform later.

## In Scope

- Interactive simulations for mathematics, physics, chemistry, and biology.
- Shared simulation lifecycle, timing, parameters, presentation mode, telemetry, rendering lifecycle, and QA foundations.
- Scientific models that are deterministic and independently testable where practical.
- Original visual language with premium scientific clarity.

## Out Of Scope

- Authentication, payments, subscriptions, LMS workflows, accounts, messaging, dashboards, recorded lesson infrastructure, and backend business systems.

## Product Standard

The product should feel modern, clear, teacher-friendly, visually premium, and scientifically honest. PhET may be used as a clarity benchmark only. Do not copy PhET code, visual identity, assets, layouts, screenshots, branding, or distinctive interaction style.
