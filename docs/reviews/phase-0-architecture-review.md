# Phase 0 Architecture Review

Date: 2026-08-25
Reviewer: Architecture Reviewer playbook
Scope: repository foundation, documentation structure, dependency/tooling baseline, initial React/Vite shell.

## Findings

### LOW: `qa:full` contains planned-test placeholders

`qa:full` currently runs fast QA and production build, then executes placeholder commands for e2e and visual tests. This is acceptable for Phase 0 because no interactive simulation exists yet, but Phase 1/2 must replace those placeholders with real Playwright and visual checks before any major simulation is declared complete.

### NOTE: `pnpm-workspace.yaml` exists for pnpm supply-chain policy state

The project is intentionally not a monorepo. The current `pnpm-workspace.yaml` does not define workspace packages; it was generated by pnpm to store minimum-release-age exclusions. Keep this file limited to package-manager policy configuration unless a future ADR approves a monorepo.

## Positive Checks

- Documentation establishes the repository as source of truth through `AGENTS.md` and `docs/CURRENT_STATUS.md`.
- Architecture docs preserve the model/controller/renderer/UI separation.
- Dependency policy is explicit and direct dependency notices were started.
- No speculative Chemistry, Biology, or Math engine code was implemented.
- Phase 0 app shell is intentionally small and does not fake simulation capabilities.
- Scientific and rendering directory guidance files reinforce the correct boundaries.

## Outcome

No BLOCKER or HIGH findings. Phase 0 foundation may proceed after documenting the known placeholders in current status and keeping the monorepo guardrail visible.
